# 织锦打样与织造跟踪台

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖；所有数据保存在浏览器本地（localStorage），刷新不丢失。

## 功能

- **色线库存**：色线标号、名称、颜色、库存与预计损耗%；实时显示在库 / 排产占用 / 机台已领 / 可排剩余；支持入库登记。
- **纹样打样**：经纬网格画布，选色线点按或拖动填色，可调整经纬尺寸；同一纹样可保存多个打样版本，随时载入继续修改。
- **循环拆步**：在版本上按横向（纬向行）或纵向（经向列）循环拆成织造步骤，自动按格数 × 每格耗线 ×（1+损耗%）计算各色线用量。
- **织造排产**：给每个步骤指定机台和日期。库存不足不能排产；同一机台同一天不能重复安排；取消排产自动退回占用库存。
- **起机与完工**：起机领料扣减库存并记流水，重复领料会被拦截；完工登记实际耗线，余线自动退回库存，重复完工会被拦截。
- **流水台账**：入库、领料、完工实耗、余线退回全部留痕。
- **导入导出**：一键导出 JSON 数据文件，导入即可完整还原版本、步骤、库存与流水。
